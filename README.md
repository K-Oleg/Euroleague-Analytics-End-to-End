# Euroleague Analytics: End-to-End Case Study

This project is a comprehensive data analysis of the Euroleague regular season across 32 rounds. It demonstrates a full data pipeline, from manual data collection to advanced visualization and tactical insights.

## Professional Background
I am a **Data Analyst** with a strong background as a **UI/UX Designer** and a **Basketball Coach**. This unique combination allows me to bridge the gap between complex raw data, tactical sports expertise, and intuitive visual communication.

## Project Workflow
The project consists of four main stages:

1. **Data Collection**: Structuring and maintaining game statistics in Google Sheets over a 7-month period.
2. **Database Engineering**: Designing a relational database schema and migrating data to SQL Server.
3. **ETL & EDA**: Data cleaning, exploratory analysis, and metric pre-calculation using Python (Pandas).
4. **BI & Visualization**: Developing an interactive dashboard in Power BI with custom DAX measures.

## Key Hypotheses and Findings
I analyzed the data to answer four critical questions:

1. **Home Court Advantage**: Evaluated how home-court impact changes under pressure. Finding: While the league average dropped, elite teams improved their home performance in the second half of the season.
2. **Shooting Efficiency**: Analyzed the sustainability of 2PT and 3PT percentages. Finding: Top-tier teams increased 2PT efficiency by 3%, while lower-tier teams saw a significant drop in 3PT accuracy.
3. **PIR Forecasting**: Used Performance Index Rating to identify the most stable teams. Finding: Top 6 teams showed much higher consistency, making their performance more predictable.
4. **Second Chance Points**: Developed a custom "Resilience Index." Finding: League leaders maintained higher discipline in offensive rebounding despite late-season fatigue compared to the rest of the league.
